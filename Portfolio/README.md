# Portfolio Project Architecture & Assets Directory

Интерактивный рабочий стол веб-дизайнера.

## Структура каталогов

```

├── 01_Reference/

│   ├── Layout/ (Схема расположения объектов)
│   └── Colors/ (Палитра)
├── 02_Background/
│   ├── Desk/ (Основной стол)
│   ├── Light/ (Световые эффекты)
│   └── Shadows/ (Тени)
├── 03_Assets/
│   ├── Laptop/ (Closed.webp, Open30.webp, Open120.webp)
│   ├── Notebook/ (Closed.webp, HalfOpen.webp, OpenBlank.webp, OpenNotes.webp)
│   ├── Camera/ (Top.webp, Angle.webp, Rotate.webp)
│   ├── Coffee/ (Empty.webp, Coffee.webp, Steam.webp)
│   ├── Smartphone/
│   ├── Mouse/
│   ├── Lamp/
│   ├── Pen/
│   ├── Envelope/
│   └── Polaroid/
├── 04_Web/
│   ├── Images/

│   ├── Videos/

├── 05_Animations/
│   ├── Laptop/

```

## Правила проекта
- Все изображения хранятся в формате WebP (с альфа-каналом для прозрачности).
- Каждый объект хранится отдельно в своей папке.
- Для каждого объекта используются отдельные файлы разных состояний.
- Анимации и оптимизированные графические ресурсы хранятся отдельно.
